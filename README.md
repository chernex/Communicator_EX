# Communicator_EX

Open-source real-time communication platform focused on voice, video and ultra-low-latency screen sharing.

## About

Communicator_EX is a desktop communication platform built with Electron, React, WebRTC and Pion.

The project focuses on high-performance communication, efficient media transport and self-hosted deployment.

## Features

* Voice communication
* Video calls
* Community channels
* 1080p 60 FPS screen sharing
* Ultra-low-latency media transmission
* Electron desktop client
* Self-hosted infrastructure
* Cross-platform architecture

## Technology Stack

* Electron
* React
* WebRTC
* Pion
* FFmpeg
* Node.js
